# Teleporty — Margonem NI

Dodatek do zarządzania teleportami w Margonem NI. Pozwala przypisać teleporty do 60 miejsc i używać ich po kolei ręcznie lub automatycznie w ustawionych odstępach czasu.

Teleporty można przeciągać z torby albo dodać przyciskiem **Pobierz teleporty**. Dodatek pokazuje czas odnowienia, pomija niedostępne teleporty i pozwala blokować wybrane miejsca w kolejce.

## Instalacja

[Zainstaluj Teleporty](https://raw.githubusercontent.com/Doiua97/teleport-queue/main/teleporty.user.js)

Do działania potrzebny jest Tampermonkey. Po zainstalowaniu odśwież grę.

## Skróty

- **F9** — użyj kolejnego teleportu.
- **F10** — uruchom lub wstrzymaj automat (po włączeniu go w ustawieniach).

Skróty można zmienić w konfiguracji dodatku.
